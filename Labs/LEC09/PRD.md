# Sonic 애니메이션 뷰어 PRD



커밋 메시지는 반드시 한글로 작성.

## 1. 문서 목적

`PRE-PRD.md`의 아이디어를 실제 구현과 확인에 사용할 수 있는 요구사항으로 구체화한다. 이 문서는 `Labs/LEC09`의 애니메이션 뷰어 개발 기준이다.

## 2. 제품 개요

- **제품명:** Sonic 애니메이션 뷰어
- **실행 파일:** `sonic_animation_viewer.py`
- **기술:** Python, pico2d
- **이미지:** `sonic-sprite.png`
- **확대 비율:** 원본 대비 3배
- **화면 크기:** 1200 × 800 픽셀
- **형태:** 단일 Python 파일로 실행하는 데스크톱 애니메이션 뷰어

스프라이트 시트에 있는 Sonic의 각 애니메이션을 크게 보여준다. 각 동작을 5회 재생하고 1초 쉰 뒤 다음 동작으로 넘어가며, 모든 동작을 재생한 다음 처음부터 계속 반복한다.

## 3. 사용자와 목표

**사용자:** 2D 게임 프로그래밍 수업의 학습자

**목표:** 스프라이트 시트의 프레임을 잘라 순서대로 재생하고, 여러 애니메이션을 정해진 순서와 반복 규칙으로 관리하는 방법을 확인한다.

## 4. 기능 요구사항

1. 1200 × 800 픽셀 크기의 pico2d 캔버스를 열고 `sonic-sprite.png`를 불러온다.
2. 구현 전에 시트를 확인해 모든 애니메이션의 프레임 영역, 프레임 수, 재생 순서를 목록화한다. 제목, 크레딧 등 장식 요소는 애니메이션에서 제외한다.
3. 각 애니메이션은 프레임을 순서대로 재생하며, 한 동작을 정확히 5회 반복한다.
4. 한 동작이 끝나면 1초 대기한 뒤 다음 동작을 재생한다.
5. 시트의 모든 애니메이션을 재생한 뒤 첫 동작부터 다시 시작해 무한 반복한다.
6. 각 프레임을 원본 대비 3배 크기로 표시한다. 캔버스 안에 들어오도록 위치를 정한다.
7. 달리기, 스핀, 구르기처럼 이동이 포함된 애니메이션은 재생 중 화면에서 좌우로 이동시킨다. 이동이 없는 동작은 화면 중앙에 표시한다.
8. 창을 닫으면 반복 재생을 종료하고 캔버스를 정상적으로 닫는다.

## 5. 범위와 제약

- 구현 파일은 `sonic_animation_viewer.py` 하나로 제한한다.
- 제공된 `sonic-sprite.png`를 사용하며, 별도 이미지나 사운드 기능은 추가하지 않는다.
- 메뉴, 사용자 입력을 통한 애니메이션 선택, 편집 기능은 이번 범위에 포함하지 않는다.
- 프레임 좌표와 애니메이션별 재생 속도는 시트와 pico2d 동작을 확인해 결정한다. 재생 속도는 애니메이션 사이에서 일관되게 관리한다.
- 개발은 작은 단위로 진행한다. 기능 구현을 한 번에 몰아서 작성하지 않는다.

## 6. 완료 기준

- `Labs/LEC09`에서 프로그램을 실행하면 오류 없이 창과 이미지가 표시된다.
- 목록화한 각 애니메이션이 올바른 프레임 순서로 재생되고, 잘못 잘린 프레임이나 장식 이미지가 나오지 않는다.
- 각 동작이 5회 재생된 후 다음 동작으로 넘어가며, 전환 전 대기 시간은 1초다.
- 마지막 동작 뒤 첫 동작으로 돌아가 반복 재생한다.
- Sonic이 화면에서 충분히 크고 잘리지 않으며, 창을 닫으면 프로그램이 종료된다.
- 개발 과정에서 의미 있는 변경을 단계별로 커밋하고, 전체 커밋 수를 최소 20개 부터 시작한다.

## 7. 개발 단계 및 커밋 체크리스트

아래 항목은 각각 작고 검증 가능한 변경으로 진행한다. 한 커밋에 여러 항목을 합치지 않고, 실제 변경 내용에 맞는 메시지를 사용한다. 커밋 메시지는 반드시 한글로 작성한다.

개발 단계를 20단계 이상으로 작성.

1. 작업 폴더와 제공 에셋 확인
2. 스프라이트 시트 크기와 그리드 조사
3. 애니메이션 후보 영역 목록 작성
4. 애니메이션 프레임 수와 순서 기록
5. 실행 파일 생성 및 pico2d 임포트 확인
6. 캔버스 생성과 종료 흐름 구현
7. 이미지 로드 및 경로 확인
8. 단일 프레임 출력
9. 프레임 잘라내기 좌표 보정
10. 단일 애니메이션 프레임 전환
11. 애니메이션 재생 속도 적용
12. 한 동작의 5회 반복 구현
13. 동작 사이 1초 대기 구현
14. 다음 동작으로 이동하는 흐름 구현
15. 나머지 애니메이션 데이터 추가
16. 모든 애니메이션의 순환 재생 구현
17. 화면 배율과 위치 조정
18. 창 닫기와 자원 종료 확인
19. 전체 재생 및 누락 프레임 점검
20. 경로, 동작, 종료를 포함한 최종 실행 확인 및 수정

## 8. 확인 방법

pico2d가 설치된 Python 환경에서 `Labs/LEC09/sonic_animation_viewer.py`를 실행한다. 화면에서 애니메이션 순서와 크롭 상태를 확인하고, 반복 횟수와 동작 사이 1초 간격을 재생 흐름으로 검증한다. 전체 순환을 확인한 뒤 창을 닫아 정상 종료 여부를 확인한다.
